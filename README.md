# Green Africa Farm (Green Africa General Trading PLC)

Premium certified grafted fruit seedlings delivered across Ethiopia.

## Tech Stack
- **Framework**: Next.js 16 (App Router, React 19, TypeScript strict)
- **Styling**: Tailwind CSS v4 with OKLCH design tokens
- **Components**: Radix Primitives / shadcn UI
- **Icons**: Lucide React + Brand Icons

## Getting Started

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the website.

### Production Build
```bash
npm run build
npm run start
```

### Checks & Quality
```bash
npm run check
```
Runs ESLint, TypeScript typecheck, and Next.js production build.
